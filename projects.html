Featured Project · #14 Mini Marketplace

Mini Marketplace Template

A full-stack digital-services marketplace concept for virtual numbers, pre-registered social accounts, and social-media boosting, with account, wallet, ordering, and administration workflows.

Challenge

Bring several digital-service categories into one storefront and give customers a consistent path from account creation and wallet funding to order delivery.

My work and decisions

Structured the project as a vanilla JavaScript storefront backed by Node.js and Express. The documented flows include password-hashed accounts, rate-limited sign-in, wallet funding, order placement, and an admin workspace.

Payments and fulfillment

The project documents Paystack funding with webhook verification and idempotency, plus manual bank-transfer credits. Stocked accounts can be delivered automatically; boosting orders can use an SMM panel, and virtual-number orders are fulfilled by an administrator.

Technologies

Node.js 18+, Express, SQLite, and vanilla JavaScript, with bcrypt password hashing and an HTTP-only JWT cookie described in the project documentation.

Deployment note: The supplied GitHub Pages URL currently displays project documentation, not the running application. Running the app requires a Node.js server, configured secrets and payment credentials, persistent storage, and any required fulfillment-provider integrations. Payment and order flows have not been verified as live.
